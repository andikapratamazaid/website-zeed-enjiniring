# Website PT. Zeed Enjiniring Construction

Website company profile PT. Zeed Enjiniring Construction: satu file HTML mandiri
(`index.html`, seluruh gambar tertanam di dalam file).

## Isi Repository

- `index.html` — halaman website lengkap. Cukup file ini untuk tayang di GitHub Pages.

## Menjalankan

- Lokal: buka `index.html` di peramban.
- Online: aktifkan GitHub Pages (Settings → Pages → Deploy from a branch → main → / (root)).
  Website tayang di `https://<username>.github.io/<nama-repository>/`.

## Catatan

- Tombol WhatsApp dan Google Maps di halaman bekerja normal di GitHub Pages.
- Fitur yang membutuhkan server (panel admin/CMS dan penyimpanan data formulir)
  berjalan di aplikasi backend Flask terpisah (repository backend), bukan di GitHub Pages.
